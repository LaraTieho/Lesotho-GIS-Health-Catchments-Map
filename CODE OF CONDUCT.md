# Code of Conduct

## Our Commitment

We are committed to maintaining a respectful, inclusive, and constructive environment for everyone contributing to or using this project. This includes maintainers, developers, GIS analysts, data stewards, ministry staff, district teams, and external partners.

## Purpose of the Project

This repository supports a public-health geospatial system used for catchment mapping, PHC planning, and EPI decision-making in Lesotho. Collaboration should therefore remain focused on data quality, transparency, accountability, and service delivery value.

## Expected Behavior

Participants are expected to:

- Be respectful and professional in all communication.
- Focus feedback on the work, not the person.
- Use clear, factual, and constructive language.
- Respect data stewardship, validation, and approval workflows.
- Recognize the public-health purpose of the project.
- Support learning, handover, and continuity of the system.
- Report issues through agreed channels rather than making unauthorized changes.

## Unacceptable Behavior

The following behaviors are not acceptable:

- Harassment, intimidation, or personal attacks.
- Discriminatory, abusive, or insulting language.
- Deliberately misleading edits or false reporting.
- Unauthorized changes to authoritative datasets or published layers.
- Repeated disruption of review, validation, or collaboration processes.
- Sharing sensitive project information outside approved channels.

## Stewardship and Accountability

Authoritative datasets are managed by designated data stewards. Contributors should respect the separation between draft, review, and published content. Changes that affect operational datasets must be reviewed and approved through the project’s established workflow.

## Reporting Concerns

If you experience or witness behavior that violates this Code of Conduct, report it to the project maintainers or the designated data steward.

Reports should include:

- A short description of the incident
- The date and time, if known
- The files, layers, or discussions involved
- Any screenshots or supporting evidence, if available

Reports will be handled confidentially and reviewed promptly.

## Enforcement

Project maintainers may take any of the following actions in response to conduct issues:

- Requesting a correction or clarification
- Issuing a warning
- Temporarily restricting contribution access
- Removing access to project resources in serious cases

## Scope

This Code of Conduct applies to all project spaces, including repository issues, pull requests, discussion threads, shared data, and project-related meetings or messaging channels.

## Acknowledgement

By participating in this project, contributors agree to follow this Code of Conduct and support a professional, collaborative environment.
